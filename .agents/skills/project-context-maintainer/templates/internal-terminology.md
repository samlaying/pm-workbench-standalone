# 内部术语表

> 项目级长期维护文件。判断标准：新来的实习生只看项目资料，不问任何人，能否准确理解这个词在本公司、本项目里的含义和边界？

## 术语分层规则

- **项目级术语**：只有这个项目会提到的术语，其他项目不涉及。
- **公司级术语**：跨多个项目都会出现的术语，存放在工作区约定的公司级术语表（如存在）。
- 项目级术语表中引用公司级术语时，用 `[[公司术语表]]` 双链标注来源。

|------|---------|-------------------|---------|---------|-------------|------|

## 引用的公司级术语

| 术语 | 公司级定义 | 本项目中的使用方式 | 状态 |
|------|-----------|-------------------|------|
| | | | 待确认/已确认 |

## 写法规范

- 定义要能直接复制进 PRD、会议纪要或任务安排。
- 优先写“它是什么 + 和本项目有什么关系 + 不包含什么边界”。
- 公司内部含义特殊的系统、登录方式、身份、权限、权益、计费、数据口径必须记录。
- 不写百科式解释；不解释读者已经懂的通用词。
