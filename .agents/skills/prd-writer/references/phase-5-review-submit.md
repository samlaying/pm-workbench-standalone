# Phase 5：提交评审

## 目标

让用户拿到可直接发给评审人的材料。

## 动作

1. 生成评审清单。
2. 输出评审说明文案，包含飞书链接、需要重点看的章节、期望反馈方式。
3. 提醒：评审结束后使用 `prd-review-handler` 拉取飞书最新评论和最新版文档进行对比处理。

## 评审清单

| 评审维度 | 重点检查项 | 建议评审人 |
|----------|------------|------------|
| 业务逻辑 | 流程是否完整、分支是否覆盖、边界是否清晰 | MT/产品 |
| 交互体验 | 异常提示、状态变化、页面路径是否合理 | 设计/产品 |
| 可落地性 | 依赖、约束、风险是否可接受 | 研发 |
| 验收准备 | 是否能基于流程写验收标准 | 测试/产品 |
