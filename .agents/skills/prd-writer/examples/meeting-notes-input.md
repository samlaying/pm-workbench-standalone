# 示例输入：MT会议纪要

## 会议信息
- 日期：2025-01-20
- 参会人：MT（王总）、产品经理（小明）、前端（小李）、后端（小张）
- 主题：注册功能需求讨论

## 会议内容（口语化原始记录）

王总说：现在新用户注册太慢了，每次都要我们后台手动开账号，一天开几十个，
业务那边天天抱怨。我们要做个用户自己注册的功能。

先做手机号验证码注册就行，微信登录什么的后面再说。

对了验证码有效期别太长，5分钟吧。还有，我们后面可能要做海外业务，
所以手机号要考虑一下区号的问题，但是第一期先把大陆的做好。

还有一个事，注册完了别直接跳首页，引导用户把公司名、联系人这些信息填一下，
不然用户注册完就走了，资料不全我们后面运营也没法跟进。

小李问：那如果手机号已经注册过了怎么办？
王总说：提示他直接登录就行。

小张问：验证码发几次？连续点怎么办？
王总说：搞个倒计时，60秒之内不能重复点。后端也做个限制，3秒内算一次。
