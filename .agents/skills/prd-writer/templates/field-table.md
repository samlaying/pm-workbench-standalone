## 字段维度行写法参考

| 字段名 | 必填 | 样式 | Placeholder | 校验规则 | 校验失败提示 | 备注 |
|--------|------|------|-------------|---------|-------------|------|
| 手机号 | 是 | 文本框 | 请输入手机号 | 11位纯数字，首位为1，前三位匹配运营商号段 | 请填写正确的手机号 | |
| 验证码 | 是 | 文本框 | 请输入验证码 | 与已发送验证码匹配，有效期10分钟 | 验证码错误或已过期 | 不校验格式，只校验匹配 |
| 区号 | 是 | 下拉框 | — | 枚举选择，无需校验 | — | 默认中国大陆+86 |

## 交互维度行写法参考

| 元素 | 状态 | 行为 | 备注 |
|------|------|------|------|
| 【发送验证码】按钮 | 点击后 | 置灰60秒，显示倒计时 | 60秒内不可重复点击 |
| 【发送验证码】按钮 | 60秒倒计时内 | 前端不可点击；后端3秒内视为同一次请求 | 防连击 |
| 【注册】按钮 | 校验未通过 | 置灰，不可点击 | |
| 注册成功 | — | Toast提示"注册成功" | 轻提示，2秒后自动消失 |
| 手机号已注册 | — | Toast提示"该手机号已注册，请直接登录" | |
| 验证码错误 | — | Toast提示"验证码错误，请重新输入" | |
| 页面加载中 | — | 全屏Loading | |
